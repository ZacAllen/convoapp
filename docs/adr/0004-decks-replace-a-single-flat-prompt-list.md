# Decks replace a single flat prompt list

Prompts are now grouped into named decks — *Small Talk* and *Business Calls* —
selectable on the title screen, with a *Mixed* option that pools them.

This reverses an earlier decision to keep one uncategorised list, recorded then
as "a filing system for a collection that does not exist yet; real small talk
arrives uncategorised". That reasoning held while every prompt came from one
domain. Business calls are not a subdivision of small talk: they have a
different register, a different failure mode, and carry a Scene that social
prompts never do.

## Consequences

The original argument is preserved rather than discarded: **Mixed** keeps the
unfiltered draw available, and is the default, so the realistic
you-do-not-get-warned case remains the normal way to practise. The narrow decks
serve deliberate practice instead.

`Deck` changed meaning in the glossary — it was the whole prompt list, it is now
one named collection.
