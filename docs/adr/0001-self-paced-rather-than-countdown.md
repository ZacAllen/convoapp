# Self-paced cards, not a countdown

The app was conceived as "timed flash-cards", which implies a shot clock on each
card. We chose instead to show the prompt with no countdown, let the user end
the card with a tap, and time it silently in the background.

Real conversation presents no visible timer, so a drill that makes you fluent
*with* one risks training a reflex that does not transfer. The stopwatch
measures pressure rather than creating it.

## Consequences

Nothing ends a card but the user, so a run needs an explicit length — hence the
card-count setting and the endless option. It also means the app has no way to
cut short a card the user has abandoned.
